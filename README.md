\# 🏠 Airbnb Clone



A full-stack Airbnb-inspired web application built using the MERN stack.



\## 🛠️ Tech Stack



\- React.js

\- Vite

\- Tailwind CSS

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- JWT \& bcrypt



\## ✨ Features



\- User registration \& login

\- JWT-based authentication

\- Secure password hashing

\- MongoDB database integration

\- Responsive React UI
